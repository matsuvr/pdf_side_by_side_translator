# Offline PDF Translator

PDFの原文を左に、日本語訳を右に表示するオフライン翻訳アプリです。
読んでいるページをローカルのPLaMo 3 Translate 0.8Bで翻訳します。

Built with PLaMo

## 使い方

1. [リリースページ](https://github.com/matsuvr/pdf_side_by_side_translator/releases/latest)から、使うOSのZIPをダウンロードして展開します。
2. Windowsでは `offline-pdf-translator.exe`、Macでは `Offline PDF Translator.app` を起動します。
3. 「モデル設定」で、同梱の `plamo-3-translate-0.8b-Q4_K_M.gguf` を選択します。
4. PDFを開きます。左に原文、右に現在のページの日本語訳が表示されます。

原文の左右の矢印でページを移動します。ページ番号を入力すると、そのページへ移動します。
PDFの倍率は原文枠の上部で、訳文の文字サイズは「表示」メニューで調整します。
原文や訳文の必要な部分を選択してコピーします。

## 文書データの扱い

原文、訳文、原文の手編集、読書位置、モデルの選択、診断情報は、アプリの起動中だけメモリ内で保持します。
キャッシュや設定のファイルを自動作成しません。アプリ終了後に次回へ引き継ぐデータもありません。
起動するたびに「モデル設定」でGGUFを選択してください。

必要な訳文は「ファイル」メニューから明示的に書き出します。
「この起動中の原文編集・設定を書き出す」は、手編集を含むセッション状態を選んだ場所へSQLiteファイルとして保存します。
このファイルを次回起動時に自動で読み込む機能はありません。
通常の書き出し先は上書きできますが、現在選択しているPDF・GGUFや、その同じファイルを指す別名への書き出しは拒否します。
終了操作は、受け付けた書き出しが完了するまで待ちます。書き出しに失敗した場合は画面を残し、内容を保持して再試行できます。

翻訳キャッシュには、開いている文書も含めたメモリ予算があります。
古い訳文はキャッシュから外れるため、「完成したページの訳文を書き出す」の対象は、その時点で保持している完成訳です。
必要な結果は適宜書き出してください。原文の手編集はキャッシュの整理では消えません。
非常に複雑なページでは自動文字抽出を止め、PDF表示と原文の手入力を継続できます。

旧版の保存ファイルは自動で読み込まず、自動削除もしません。
以前のデータが不要になった場合の対象ファイルと確認手順は、[セッションデータの仕様](docs/session-data.md)を参照してください。

## ショートカット

Ctrl（⌘）はWindowsではCtrl、Macでは⌘キーです。

| 操作 | キー |
| --- | --- |
| PDFを開く | Ctrl（⌘）＋O |
| ページ番号へ移動 | Ctrl（⌘）＋G |
| PDF内を検索 | Ctrl（⌘）＋F |
| 選択したテキストをコピー | Ctrl（⌘）＋C |
| モデル設定 | Ctrl（⌘）＋, |
| ペイン間の移動 | F6 / Shift＋F6 |

## モデルとライセンス

対応モデルはPLaMo 3 Translate 0.8B（英語→日本語）です。
リリースZIPには、公式のQ4_K_M GGUFと `PLaMo-Community-ja.txt` を同梱しています。
モデルの利用条件は、このPLaMoコミュニティライセンス契約をご確認ください。
