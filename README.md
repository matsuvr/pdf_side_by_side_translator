# Offline PDF Translator

PDFの原文を左に、日本語訳を右に表示するオフラインPDFビューワーです。
読んでいるページをローカルのPLaMo 3 Translate 0.8Bで翻訳します。

Built with PLaMo

## 使い方

1. 使うOSの **0.1.2 以降**のZIPを展開します。[リリース一覧](https://github.com/matsuvr/pdf_side_by_side_translator/releases)で配布物の版を確認できます。0.1.1 以前には文書データをディスクに保存する機能があります。
2. Windowsでは `offline-pdf-translator.exe`、Macでは `Offline PDF Translator.app` を起動します。同じフォルダーの `plamo-3-translate-0.8b-Q4_K_M.gguf` を自動で読み込みます。
3. PDFを開きます。左に原文、右に現在のページの日本語訳が表示されます。

同梱GGUFが見つからない場合だけ、起動時にファイル選択画面が開きます。
選択をキャンセルしてもPDFを閲覧でき、後から「モデル設定」でGGUFを選べます。

原文の左右の矢印でページを移動します。ページ番号を入力すると、そのページへ移動します。
PDFの倍率は原文枠の上部で、訳文の文字サイズは「表示」メニューで調整します。
原文や訳文の必要な部分を選択してコピーします。本文は読み取り専用です。
文書・原文・訳文の編集、原文の手入力、強制再翻訳、書き出しは行いません。

## 文書データの扱い

原文、訳文、読書位置、モデルの選択、診断情報は、アプリの起動中だけメモリ内で保持します。
作業ファイル、キャッシュ、状態DB、設定、履歴、ログ、一時ファイルをローカルに作成しません。
入力PDF・GGUFを変更せず、コピーや書き出しファイルも作りません。以前の版が作成したファイルを読み込んだり削除したりする処理もありません。
終了後に次回へ引き継ぐデータはありません。モデルの場所も保存せず、毎回同梱GGUFを使います。

表示用の訳文・描画キャッシュは、メモリ予算の範囲で保持します。
非常に複雑なページでは自動文字抽出を止めますが、PDFは引き続き閲覧できます。
詳細は[セッションデータの仕様](docs/session-data.md)を参照してください。

## ショートカット

Ctrl（⌘）はWindowsではCtrl、Macでは⌘キーです。

| 操作 | キー |
| --- | --- |
| PDFを開く | Ctrl（⌘）＋O |
| ページ番号へ移動 | Ctrl（⌘）＋G |
| PDF内を検索 | Ctrl（⌘）＋F |
| 選択したテキストをコピー | Ctrl（⌘）＋C |
| モデル設定 | Ctrl（⌘）＋, |
| ペイン間の移動 | F6 / Shift＋F6 |

## モデルとライセンス

対応モデルはPLaMo 3 Translate 0.8B（英語→日本語）です。
リリースZIPには、公式のQ4_K_M GGUFと `PLaMo-Community-ja.txt` を同梱しています。
GGUFはWindowsの `.exe` と同じ階層、Macの `.app` の外側の同じ階層に置きます。
モデルの利用条件は、このPLaMoコミュニティライセンス契約をご確認ください。
