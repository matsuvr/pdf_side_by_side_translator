Offline PDF Translator
Built with PLaMo

Application source and original fixtures: MIT (LICENSE).
Models: PLaMo Community License. The Windows and macOS models are independently quantized from the pinned PFN BF16 weights.
See deps/models.json and licenses/PLaMo-*.txt.

PDF rendering and extraction use hayro and its Rust dependencies, including
its embedded standard font and Adobe CMap data. Windows inference uses the
project's Rust PLaMo engine. macOS inference uses Rust kernels compiled with CubeCL for Apple Metal. Native user interfaces use Microsoft WinUI 3 and
Apple SwiftUI / AppKit. Font selection and OCR use OS facilities.

The target-specific THIRD_PARTY_NOTICES.txt in a release is generated by
scripts/collect_notices.py from the locked Cargo graph, embedded assets,
native deployment packages and upstream notices. The release includes the Rust
standard library copyright notices and the applicable model agreements.
