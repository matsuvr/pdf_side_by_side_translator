# 実際のPDFを日本語に訳す速度の比較

PFN公式実装との入力一致を確認した修正後のビルドで、同じ10ページを再測定した。[修正後の10言語の速度比較](speed-after-reference.md)

2026年11月27日、Windows上で、出入国在留管理庁の『生活・就労ガイドブック』にある在留カードの案内を、10言語から通常の日本語に翻訳した。各版の本文2ページ目を丸ごと入力した。ページ内には空港名、住所の届出期限、箇条書きや欄外の章見出しがある。版によって改ページ位置が異なり、紛失時の手続きも載る言語がある。[公開ガイドブック](https://www.moj.go.jp/isa/support/portal/guidebook_all.html?hl=en)

翻訳時間は、推論ワーカーが1ページの入力トークンを評価し、日本語を生成して終了理由を返すまで。起動から終了までの実時間には、モデル読込、PDFを開いて指定ページを抽出する処理、トークン化、プロセス終了を含む。読込とPDF抽出は並行する。「実効出力トークン/秒」は、各ページの出力トークン数の中央値の合計を、翻訳時間の中央値の合計で割った値で、入力評価の時間も含む。

## 実行条件

- Windows 11 Pro build 26300、Intel Core i9-13900（8 Pコア＋16 Eコア、32論理CPU）。Windows x64 Release、CPU推論8スレッド。CPUの割り当ては各実装の標準動作を使用した。
- 3構成とも製品と同じPDFium・読み順抽出・ページ翻訳経路を通る開発用 `translation_probe.exe` を使用した。各回で公式のPDF全体を開き、指定した物理ページの全文を、原文言語自動判定・標準日本語・greedy生成で訳した。OCR、原文の修正、訳文キャッシュの再利用は使用していない。
- OSのファイルキャッシュを暖め、短い別PDFで各構成を1回ずつ事前実行した後、各試行でプロセスとモデルを新しく開いた。3構成を順次実行し、各言語で各構成が先頭・中央・末尾に1回ずつ来るようにした。翻訳ジョブは同時実行していない。
- 各言語で、全試行の原文SHA-256と入力トークン数が一致した。全90試行でページが1チャンクで正常終了し、終了コード0と、かなを含む日本語出力を確認した。全訳文に「空港」と「14」（全角・漢数字を含む）があった。CSVの `output_has_airport` と `output_has_14` がこのガイドブック用の確認値。全30条件で、同じ実装・同じPDFの3回の訳文SHA-256が一致した。
- 提供元とモデルが共通して対応する言語から、日本語への翻訳を測れる10言語を選んだ。各言語1ページの行政案内を扱う速度比較であり、分野ごとの翻訳品質や、意味の脱落までは採点していない。[モデルの対応言語](https://huggingface.co/pfnet/plamo-3-translate-0.8b)

## ヒンディー語の追加測定

ガイドブックのヒンディー語版では、PDFiumの抽出原文に59個の置換文字（U+FFFD）が含まれた。他の9言語は0個だった。また、各版の欄外に印刷された章見出しの一部は、読み順抽出によって逆順や本文への混入となった。これらもビューアーが渡す原文の一部としてそのまま測定した。

その後、置換文字を検出したページを画像から読み直すように修正した。この表は修正前の値を記録している。[修正後のヒンディー語の実測と53言語の入力照合](unicode.md)

独立したヒンディー語の例として、ニューヨーク市発行のIDNYC申請書にある申請要件・本人確認書類の案内（物理2ページ目の全体、US Letter 612 × 792 pt）を同じ条件で測った。この追加9試行は上の10ページの合計に含めていない。[市の公開PDF・2ページ目](https://www.nyc.gov/assets/idnyc/downloads/pdf/application-materials/application_hindi.pdf?download=1#page=2)

抽出原文は7,686文字、置換文字は0、入力は7,574トークン。PDFのSHA-256は `843131355507976cc74052827c0e812b698fd9afac6041eba120af8c83959c0c`。全9試行で正常終了した。

```powershell
$env:OPT_INFERENCE_THREADS = '8'
$bench = '.work/bench-10lang-20261127'

& "$bench/vanilla-probe.exe" $gguf cpu $pdf --page=17
```
