# Offline PDF Translator 0.2.1

検証日: 2026-11-16（日本時間）

## 変更

- 原文の言語ヒントを `en` に固定せず、PLaMo 3 Translate にページごとの言語判定を任せた。日本語・英語を含む53言語のPDFを、その言語に合った条件で日本語へ翻訳する。
- `ModelProfile` を `prompt_version=2`、`source_language=auto` に更新し、旧プロンプトの訳文を再利用しないようにした。
- アプリ内の「操作方法」、README、マニュアル、変更履歴を53言語対応の記述へ更新した。

## 確認結果

- Windows x64 Releaseビルド成功（clang-cl / Ninja）。CTest 32件合格。
- 公式tokenizerの参照token列14件が一致。固定ベクトルは `source_lang="en"` で生成されているため、`inference_probe` は属性4トークンを戻して照合し、同時にアプリのプロンプトがその4トークンを除いた形であることを検査する。
- 同梱Q4_K_M（SHA-256 `70891ec7…`）で、英語・中国語・フランス語の原文を標準文体・やさしい文体の双方で日本語へ翻訳した。訳文に仮名が含まれることを試験条件に追加した。
- P01 PDFのページ全文をPDFから翻訳し、完了状態と日本語出力を確認した。P06の日本語PDFは同文で返り、原文を崩さない。
- 配布ZIPを展開して起動し、ウィンドウ表示と同梱GGUFの読込を確認した。
- パッケージのPE監査、同梱物のハッシュ照合、ZIP往復後の実行ファイル一致を確認した。
- macOS arm64 Releaseビルド成功（Xcode 27.2 / SDK 27.2、Ninja）。CTest 31件合格。
- macOSの実モデル試験はMetalで実行し、公式tokenizerの参照token列14件の一致、準備処理の境界、キャンセル、出力上限、context reset、容量超過の拒否を確認した。
- `translation_probe` でP01 PDFのページ全文をPDFから翻訳し、標準文体で日本語の完了状態を確認した。
- macOS配布ZIPを展開して起動し、`.app` に隣接するGGUFをMetalで読み込み、ステータスバーの `Metal / CPU` 表示を確認した。
- パッケージのMach-O監査、同梱物のハッシュ照合、ZIP往復後の実行ファイル一致、ad-hoc署名の検証を確認した。
