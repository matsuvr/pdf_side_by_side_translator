# Offline PDF Translator 0.1.1

検証日: 2026-11-11（日本時間）

## 変更

- 現在ページの翻訳に絞り、全ページ翻訳のメニュー、ショートカット、背景処理と専用状態を削除。
- モデル設定のデバイス選択と旧CPU指定の復元を削除。
- やさしい文体を公式の `ja-easy` promptに対応。
- READMEと操作方法を、起動・読書・コピー・キャッシュ保存先の説明に整理。
- 署名後の実行ファイルを基準にZIP再展開後のハッシュを照合。

## 確認結果

- macOS arm64 Releaseビルド成功。
- CTest 23件合格。廃止した一括翻訳の専用テスト1件を削除し、旧ショートカットが通常入力として扱われることを確認。
- Metalの実モデルで標準／やさしい文体の生成が完了。公式tokenizerの完全prompt 14件が一致。
- P01 PDFのページ全文をMetalで翻訳し、完了状態と日本語出力を確認。
- 製品アプリの「翻訳」メニューから全ページ翻訳が消えたことを確認。
- 独立した保存先で製品アプリを起動し、P01のキャッシュは現在ページの完了1件のみ。
- 300ページのP09を開き、現在ページの入力容量超過を処理した後もプロセスが動作。翻訳試行はページ0の1件のみ。
- 両方の起動で旧 `backend=cpu` 設定を用意し、診断ログの `backend=Metal` を確認。
- 公開履歴と作業ツリーの検査で検出事項0件。

## 成果物

v0.1.1の配布対象はmacOS 14以降のApple Silicon版。
公式Q4_K_M GGUF、README、PLaMoコミュニティライセンス契約をZIPへ同梱する。
ビルドとパッケージの識別情報は、アプリ内のBUILD-INFO.jsonと配布時のpackage-manifest.jsonへ記録する。
Macパッケージはad-hoc署名。

Windows x64の既存配布物はv0.1.0。このMacで行ったv0.1.1の検証とは別の記録として扱う。
