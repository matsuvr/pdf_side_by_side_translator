# ネイティブ版の検証

2026年11月27日にWindows x64とApple M4搭載のMacでリリース構成をビルドした。各OSで同梱形式のPLaMoモデルを使い、P01の第1・第2ページを実際に翻訳した。第1ページに戻るとメモリ内の訳を再利用する。

| 確認した項目 | Windows | Mac |
| --- | --- | --- |
| 実モデル | P4X86 S4 v7、Rust CPUカーネル | 公式Q4_K_M GGUF、固定版llama.cpp |
| ネイティブUI | WinUIのページ移動・選択可能な原文と訳文をUI Automationで確認 | SwiftUIのウィンドウとNSTextViewの訳文・選択・編集不可・終了をAppKitで確認 |
| 訳文のフォント | WinUI本文スタイル。検証機の日本語本文はYu Gothic UI | 実際のNSTextViewのフォントをAppKitの本文用システムフォントと照合 |
| PDF | 単段・段組み・CropBox・回転・変換行列・Unicode・日本語代替フォント・パスワード付きPDF | 同一fixtureで確認 |
| 文字認識 | Windows.Media.Ocrでページ画像の英語を認識 | Visionで同じページ画像の英語を認識 |
| 非同期処理 | 高速ページ移動、モデル欠落時の原文表示、別PDFのパスワード待ちで旧結果を破棄 | 同じRustの回帰テストで確認 |

Windowsでは、53言語各1ページの検証PDFから取り出した本文が、全ページで元のテスト文と一致した。両OSで、PDFの `ActualText` による文字指定、右から左に読む語順、クリップ範囲外の文字を除く処理も確認した。Windowsでは、相互参照表を4 GiBより後ろに置いた疎なPDFでも、元のPDFと同じ本文を取得できた。

Windows版の推論エンジンでは、実モデルの多言語トークナイザー、カーネル、ワーカープールのテストも実行した。配布用の署名・公証、旧OSでの起動、全言語のOCR精度は今回の検証範囲外。ビルドと追試の手順は[開発手順](development.md)を参照。
