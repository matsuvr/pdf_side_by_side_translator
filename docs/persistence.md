# ビューワーのメモリ内状態

現在の仕様は [session-data.md](session-data.md) と [AGENTS.md](../AGENTS.md) を参照してください。

原文・訳文は選択・コピーできる読み取り専用の表示です。編集、強制再翻訳、書き出しはありません。
原文はPDFから抽出した文章だけを使用します。編集用ダイアログ、原文の上書き状態、強制キャッシュ無視、状態DBや訳文の書き出しAPIは削除しました。

SQLiteは `:memory:` で開き、journalと一時処理もメモリ内に限定します。
`SQLITE_TEMP_STORE=3` をビルド時にも指定し、一時ファイルへ退避しません。
翻訳状態の更新はページと翻訳条件ごとにまとめ、キューを64件、翻訳キャッシュを既定256 MiBに制限します。
ファイルのfingerprintは開いている同じファイルから段階的に計算し、PDF/GGUFを変更しません。
読書位置と表示設定は起動中だけメモリ内で保持します。終了すると全て破棄します。

ファイル出力・一時ファイル作成・旧版データの読込や削除はありません。
