はじめに

アプリの入手方法

最新のリリースページを開き、「Assets」欄からご利用のOSに合ったZIPファイルを保存したうえで、フォルダーごと展開してください。

OS別の対応ファイル
環境ZIPファイル名の末尾起動するファイル
Windows x64windows-x64-release.zipoffline-pdf-translator.exe
macOS 14以降 / Apple Siliconmacos-arm64-release.zipOffline PDF Translator.app

フォルダー構成と配置条件

書庫の中にはプログラム本体や翻訳モデル、ライセンス文書が同梱されています。展開し終えた後も、実行ファイルとモデルファイルは同じフォルダーへ収めた状態を保ってください。

展開したフォルダー/
├─ offline-pdf-translator.exe（Windows）
│  または Offline PDF Translator.app（Mac）
├─ plamo-3-translate-0.8b-Q4_K_M.gguf
├─ PLaMo-Community-ja.txt
├─ LICENSE
├─ THIRD_PARTY_NOTICES.txt
└─ README.md

基本の立ち上げ手順

プログラムを実行すると、同じフォルダーにあるGGUFファイルを自動で読み込みます。続けて画面上の「PDFを開く」ボタン、あるいはメニューバーの「ファイル」から「PDFを開く…」へ進んだうえで、一覧から対象の文書を指定して「開く」を押してください。

契約条項への同意

初めて起動する際は画面に翻訳モデルの利用規約が現れるため、内容をよくお読みください。

macOSにおける実行許可

初めて動かす際にOS側の保護機能によって起動が止められた場合は、「システム設定」から「プライバシーとセキュリティ」内の「アプリケーションの実行許可」を開いたら、本アプリの「このまま開く」を選んでください。

Windows版の配布形式

現在配布している実行ファイルには電子署名を省いているため、必ず本プロジェクトの公式GitHub Releasesから手に入れたファイルであるか確認してください。

PDFを読む

表示領域の幅

画面中央の境界線をドラッグすると、原文と訳文それぞれの欄の幅を自在に変えられます。「表示」メニューの「左右を均等にする」を選べば、両方の幅を同一に揃えられます。

表示箇所の移動

原文の両脇にある矢印を押すと、前後のページへ進みます。特定のページへ移りたい場合は、ページ番号欄へ数字を打ち込んでEnterキーを押してください。

表示の大きさと角度

原文枠の上にある欄で「幅に合わせる」「ページ全体」といった選択肢を選ぶか、任意の倍率を直接入力してEnterキーを押すと拡大率が変わります。紙面の向きは「表示」メニューの「左回転」および「右回転」で調整できます。

訳文の書式

「表示」メニューの「訳文の文字サイズ…」から好みのポイント数を指定してください。なお、この設定はPDF側の倍率とは独立して機能します。

稼働状況の把握

読み込みや翻訳を進める間は循環する点が現れます。画面下のステータスバーを見ると、モデルの準備段階やコンピューター全体のCPU使用率の目安が分かります。翻訳が終わるまでの時間は、文書の分量と端末の性能に左右されます。

検索・選択・コピー

語句の照合

「選択・コピー」メニューから「PDF内を検索…」を呼び出して言葉を入力すると、「前の結果」や「次の結果」ボタンで該当箇所を行き来できます。英字の大文字と小文字を区別したい場合は、「英字の大文字・小文字を区別」を選択してください。用が済んだら「閉じる」を押して入力欄を片付けます。

テキストの取り出し

原文や訳文の任意の範囲を選んで、クリップボードへ複写できます。表示中のページ全体から原文をまとめて写し取りたいときは、「選択・コピー」メニューの「ページの原文をコピー」を使ってください。

翻訳の設定

自動実行の切り替え

起動直後は「翻訳」メニューの「現在ページを自動翻訳」が有効になっており、文書を開いたりページを送ったりするたびに表示中の紙面が翻訳されます。ご自身でタイミングを決めたいときは、該当項目のチェックを外してください。

原文の言語

原文の言語は指定の必要がなく、ページごとに自動で判定されます。PLaMo 3 Translate 0.8Bは日本語・英語を含む53言語に対応しているため、中国語やフランス語などで書かれたPDFも、そのまま日本語へ翻訳できます。

日本語の表現形式

「翻訳」メニューにある「標準文体」と「やさしい文体」のいずれかから、好みに合う文体を指定できます。

モデル設定

標準構成のままで運用できますが、別のファイルへ差し替える際は「モデル設定」メニューの「モデルを選択…」から「ファイルを選択…」と進み、対象のGGUFを指定して「OK」を押してください。読み込みが終わるまで待つと利用可能になります。なお、本アプリが扱えるのはPLaMo 3 Translate 0.8B系列のファイルです。

文書データの扱い

読み込んだPDFや翻訳モデル、ならびに画面上の本文はすべて読み取り専用として扱うため、元のファイルや表示内容をそのままの状態で保護します。テキストに対しては文字の入力や貼り付け、切り取り、削除、取り消しといった操作を省き、選択と複写に機能を集約しています。

動作中の状態やキャッシュはメモリ上で管理します。そのため、原文や訳文、閲覧位置、モデル選択、設定、診断情報、および起動中に開いたPDFの一覧は、アプリを閉じた時点で消去します。また、作業用の一時ファイルやデータベース、設定、履歴、ログ、ロックファイルの生成、さらに訳文や作業状態の書き出しをすべて見送った設計により、すべての処理をメモリ内で完結させます。

なお、文章や診断情報をコピーした際は、その内容がOSのクリップボードへ送られます。

困ったときは

モデル選択画面が現れた場合

初期設定の進め方は「はじめに」を、手動での切り替え手順は「モデル設定」をそれぞれご覧ください。

翻訳結果の調整

出力に関する各種の切り替えは「翻訳の設定」で確認できます。

翻訳が途中で止まる場合

「モデル設定」の画面に現れるエラーメッセージを確かめたうえで、規定のPLaMo 3 Translate 0.8B GGUFを指定し直してください。また、分量が多いページでは入出力の許容量や空きメモリが上限へ届くことがあるため、動作中の他アプリを閉じて余力を確保すると改善する場合があります。

ファイルを開く際に支障が生じた場合

保護用の暗号がかけられた文書では入力欄が現れるため、解除用のパスワードを打ち込んでください。一部のページが壊れてエラーが生じた際でも、前後の画面へ移動すると残りの箇所を閲覧できるケースがあります。

再起動後の閲覧

終了時に作業状態が消去される仕様上、改めて起動した際は対象のPDFをもう一度指定して開いてください。

動作の異常を連絡する手順

開発元へ状況を伝える際は、まず「ヘルプ」メニューの「診断情報をコピー…」から動作環境を写し取ったうえで、外部へ公開しても安全な中身か目を通してください。そのうえで、GitHub IssuesへOSやアプリの版数、発生時の操作、画面の表示内容を書き添えてお送りください。なお、PDFファイルを添える場合は、あらかじめ第三者へ公開して安全な文書であるか必ず確認してください。

機能上の条件と仕様

WindowsとMacで、右ペイン上部の「画像から読み取り (OCR)」をオンにすると、ページごとに画像内の文字をオフラインで読み取ります。読み取り言語が違っていたら、言語名をクリックして正しい言語を選んでください。そのページをすぐに読み直し、同じPDFの後続ページにも選んだ言語を使います。言語名から「自動判別に戻す」を選ぶと、ページごとの判別を再開します。別のPDFを開くとOCRはオフに戻ります。
