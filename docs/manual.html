はじめに

ZIPをダウンロードして展開する

最新のリリースページを開き、「Assets」からご利用のOSに合ったアプリ用ZIPをダウンロードし、フォルダーごと展開してください。

配布ファイルと起動するアプリ
環境ZIPの名前の末尾起動するファイル
Windows x64windows-x64-release.zipoffline-pdf-translator.exe
macOS 14以降 / Apple Siliconmacos-arm64-release.zipOffline PDF Translator.app

同梱ファイル

ZIPにはアプリ本体、翻訳モデル、ライセンス文書が同梱されています。展開後も、アプリとモデルを同一フォルダーに配置してください。Mac環境では、GGUFファイルを.appの外側に配置してください。

展開したフォルダー/
├─ offline-pdf-translator.exe（Windows）
│  または Offline PDF Translator.app（Mac）
├─ plamo-3-translate-0.8b-Q4_K_M.gguf
├─ PLaMo-Community-ja.txt
├─ LICENSE
├─ THIRD_PARTY_NOTICES.txt
└─ README.md

アプリを起動してPDFを開く

  1. アプリを起動します。 同一フォルダーにある GGUF が自動的に読み込まれます。
  2. 「PDFを開く」ボタンをクリックするか、メニューバーの 「ファイル」 → 「PDFを開く…」 を選択します。
  3. 表示されたファイル選択ダイアログで開きたい PDF を選び、「開く」 をクリックします。

初回の利用条件確認

初回起動時にモデルの利用条件が表示されたら、必ず内容を確認してください。

Macで初めて起動するとき

macOSが起動をブロックしたときは、「システム設定」→「プライバシーとセキュリティ」→「アプリケーションの実行許可」を開きます。Offline PDF Translatorの「このまま開く」を選択し、実行を許可してください。

Windows未署名の注意

現在配布中のWindows実行ファイルは未署名です。必ず、このプロジェクトのGitHub Releasesから取得したファイルであることを確認してください。

PDFを読む

原文と訳文を見比べる

  • 中央の境界をドラッグすれば、各欄の幅を自由に調整できます。
  • 「表示」→「左右を均等にする」を選択すると、左右の幅が同一になります。

ページを移動する

  • 原文の左右に配置された矢印を使用して、前後のページへ移動できます。
  • ページ番号欄にページ番号を入力し、Enterキーを押すと、指定したページへ移動します。

PDFの倍率・向きを変える

  • 原文枠の上部に配置された倍率欄から、「幅に合わせる」「ページ全体」または任意の倍率を選択してください。
  • 倍率を直接入力し、Enterキーを押すことでも変更できます。
  • PDFの向きは「表示」メニューの「左回転」または「右回転」で変更できます。

訳文の文字サイズを変更する

  • 「表示」メニューから「訳文の文字サイズ…」を開き、ポイント数を指定してください。
  • 訳文の文字サイズとPDFの倍率はそれぞれ個別に調整できます。

処理の状態を確認する

  • PDFの読込み中や翻訳中は、点が循環して処理中であることを示します。
  • 画面下部のステータスバーには、モデルの読込み状態やコンピューター全体のCPU使用率の概算などが表示されます。
  • 翻訳に要する時間は、ページの長さとコンピューターの性能に応じて変わります。

検索・選択・コピー

PDF内を検索する

  • 「選択・コピー」→「PDF内を検索…」を選択して検索欄を開きます。
  • 検索語を入力し、「前の結果」や「次の結果」を使って検索結果を移動します。
  • 大文字と小文字を区別したいときは「英字の大文字・小文字を区別」を選択します。
  • 検索が完了したら「閉じる」を選択して検索欄を閉じます。

必要な文章をコピーする

  • 原文または訳文の文章を選択し、コピーします。
  • 現在のページから抽出した原文をまとめてコピーしたいときは、「選択・コピー」→「ページの原文をコピー」を選択します。

翻訳の設定

現在のページを自動で翻訳する

  • 起動時に「翻訳」→「現在ページを自動翻訳」が有効になります。
  • PDFを開いたときやページを移動したときに、現在表示中のページが翻訳されます。
  • 自動翻訳を停止したい場合は、該当項目のチェックを外してください。

日本語の文体を選ぶ

  • 「翻訳」メニューの「標準文体」または「やさしい文体」から希望の文体を選択してください。

翻訳結果を原文と照合してください。

  • モデルが翻訳を行う際に、誤訳や情報の欠落が発生することがあります。

モデル設定

「モデル設定」→「モデルを選択…」を開く。

「ファイルを選択…」から対応する GGUF を選ぶ。

「OK」を押し、読み込みが完了するのを待つ。

対応モデルは PLaMo 3 Translate 0.8B（英語→日本語）です。この系列以外の GGUF は対象外となります。

文書データの扱い

  • 入力PDFとGGUFは読み取り専用で開き、変更・削除・コピーはできません。
  • 本文は読み取り専用で、入力・貼り付け・切り取り・削除・Undoは無効です。選択・コピーは可能で、検索語・ページ番号・倍率・モデルの場所は入力できます。
  • 状態とキャッシュはメモリ内で管理し、原文・訳文・読書位置・モデル選択・設定・診断情報および「この起動中に開いたPDF」の一覧はアプリ終了時に破棄されます。
  • ファイル出力は非対応です。作業ファイル、一時ファイル、状態DB、設定、履歴、ログ、lockの自動作成、訳文やセッションの保存・書き出しは行いません。
  • 文章や診断情報をコピーすると、その内容がOSのクリップボードに渡されます。

0.1.1以前を使ったことがある方へ

  • 旧バージョンで作成された保存データはそのまま保持され、管理は利用者が行います。保存場所については、セッションデータの仕様をご覧ください。

困ったときは

モデル選択画面

配置方法は「はじめに」を、手動選択は「モデル設定」を参照してください。

訳文表示

訳文表示は「翻訳の設定」で確認できます。

翻訳失敗

翻訳失敗時は「モデル設定」に表示されるエラーメッセージを確認し、該当する PLaMo 3 Translate 0.8B GGUF を選択してください。ページが長いと入力・出力容量や利用可能メモリの上限に達することがあります。メモリが不足している場合は、他のアプリを終了して確保してください。

読込失敗

パスワードが設定された PDF を開くと入力画面が表示されますので、そこでパスワードを入力してください。ページが破損して読込みエラーが起きた場合は、別のページへ移動することで閲覧できる場合があります。

再起動

再起動した場合は、PDF を再度開いて閲覧してください。

報告

「ヘルプ」→「診断情報をコピー…」で診断情報を確認・コピーできます。公開内容を確認したら、GitHub Issues に OS、アプリのバージョン、問題が起きた操作、画面に表示された状態を記入してください。公開の可否を確認する前に PDF を添付することは禁止されています。

制約

画像で構成された PDF は文字抽出・翻訳・OCR の対象外であり、画像ページや文字情報が多く検索を省略したページは検索対象外です。非常に複雑なページでは自動文字抽出が停止することがありますが、文字抽出に失敗した場合でも閲覧は可能です。
