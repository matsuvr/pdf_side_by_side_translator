はじめに

Offline PDF Translatorは、左側にPDFの原文、右側に日本語訳を表示するデスクトップアプリです。PDFから抽出した英語の原文を、同梱のPLaMo 3 Translate 0.8Bを用いて日本語に翻訳します。

アプリはPDFの閲覧と翻訳に使います。

ダウンロードしたアプリで翻訳を行います。本文は読み取り専用で、文章の選択とコピーが可能です。文書の編集、保存、書き出しは対象外です。

1. ZIPをダウンロードして展開する

最新のリリースページを開き、「Assets」からご利用のOSに合ったアプリ用ZIPをダウンロードします。ダウンロードしたZIPはフォルダーごと展開してください。「Source code」は開発用ソースコードです。起動には、下表のアプリ用ZIPを使用します。

2. アプリとモデルを同じフォルダーに置く

ZIPにはアプリ本体、翻訳モデル、ライセンス文書が同梱されています。展開後も、アプリとモデルを同一フォルダーに配置してください。

展開したフォルダー/
├─ offline-pdf-translator.exe（Windows）
│  または Offline PDF Translator.app（Mac）
├─ plamo-3-translate-0.8b-Q4_K_M.gguf
├─ PLaMo-Community-ja.txt
├─ LICENSE
├─ THIRD_PARTY_NOTICES.txt
└─ README.md

Mac環境では、GGUFファイルを.appの外側に配置します。GGUFと.appが同一階層になるよう並べてください。

3. アプリを起動してPDFを開く

アプリを起動すると、同一フォルダー内のGGUFが自動的に読み込まれます。「PDFを開く」ボタン、または「ファイル」→「PDFを開く…」からPDFを選択すると、現在表示中のページの翻訳が開始されます。

初回起動時にモデルの利用条件が表示されたら、必ず内容を確認してください。同梱のGGUFの探索に失敗した場合、モデル選択画面が開きます。この画面でキャンセルしてもPDFの閲覧は継続できます。その後、「モデル設定」からGGUFを選択し、翻訳を開始できます。

Macで初めて起動するとき

macOSが起動をブロックしたときは、「システム設定」→「プライバシーとセキュリティ」→「アプリケーションの実行許可」を開きます。Offline PDF Translatorの「このまま開く」を選択し、実行を許可してください。

現在配布中のWindows実行ファイルは未署名です。必ず、このプロジェクトのGitHub Releasesから取得したファイルであることを確認してください。

PDFを読む

原文と訳文を見比べる

左側にPDFが表示され、右側に現在表示中のページの日本語訳が表示されます。中央の境界をドラッグすれば、各欄の幅を自由に調整できます。「表示」→「左右を均等にする」を選択すると、左右の幅が同一になります。

ページを移動する

原文の左右に配置された矢印を使用して、前後のページへ移動できます。ページ番号欄にページ番号を入力し、Enterキーを押すと、指定したページへ移動します。Ctrl / ⌘ + G を使用してページ番号欄へ移動できます。

PDFの倍率・向きを変える

原文枠の上部に配置された倍率欄から、「幅に合わせる」「ページ全体」または任意の倍率を選択してください。倍率を直接入力し、Enterキーを押すことでも変更できます。PDFの向きは「表示」メニューの「左回転」または「右回転」で変更できます。

訳文の文字サイズを変更する

「表示」メニューから「訳文の文字サイズ…」を開き、ポイント数を指定してください。訳文の文字サイズとPDFの倍率はそれぞれ個別に調整できます。

処理の状態を確認する

PDFの読込み中や翻訳中は、点が循環して処理中であることを示します。画面下部のステータスバーには、モデルの読込み状態やコンピューター全体のCPU使用率の概算などが表示されます。翻訳に要する時間は、ページの長さとコンピューターの性能に応じて変わります。

検索・選択・コピー

PDF内を検索する

  1. 「選択・コピー」→「PDF内を検索…」を選択するか、Ctrl / ⌘ + F を押して検索欄を開いてください。
  2. 検索語を入力し、「前の結果」や「次の結果」を使って検索結果を移動します。
  3. 大文字と小文字を区別したいときは「英字の大文字・小文字を区別」を選択してください。検索が完了したら「閉じる」または Esc を押して検索欄を閉じます。

PDFから抽出した原文を検索します。画像で構成されたページは検索対象外です。また、文字情報が多く検索を省略したページの結果も表示対象外となります。

必要な文章をコピーする

原文または訳文の文章を選択し、Ctrl / ⌘ + C を押してください。現在のページから抽出した原文をまとめてコピーしたいときは、「選択・コピー」→「ページの原文をコピー」を選択します。

本文は読み取り専用です。本文に対する入力、貼り付け、切り取り、削除、Undoによる変更は無効です。検索語、ページ番号、倍率、モデルの場所は閲覧操作のために入力できます。

翻訳の設定

現在のページを自動で翻訳する

起動時に「翻訳」→「現在ページを自動翻訳」が有効になります。PDFを開いたときやページを移動したときに、現在表示中のページが翻訳されます。自動翻訳を停止したい場合は、該当項目のチェックを外してください。

日本語の文体を選ぶ

「翻訳」メニューにある「標準文体」または「やさしい文体」から希望の文体を選択してください。「やさしい文体」を選択すると、やさしい日本語での翻訳をモデルに指示します。

翻訳結果を原文と照合してください。

モデルが翻訳を行う際に、誤訳や情報の欠落が発生することがあります。画像内の文字を認識するOCRは対象外となります。文字の抽出に失敗しても、PDFの閲覧は引き続き可能です。

モデル設定

通常はZIPに同梱された plamo-3-translate-0.8b-Q4_K_M.gguf を使用します。手動でモデルを選択する場合は、次の手順で設定してください。

  1. 「モデル設定」→「モデルを選択…」を開いてください。Ctrl / ⌘ + , でも開くことができます。
  2. 「ファイルを選択…」から対応するGGUFを選んでください。
  3. 「OK」を押し、読込みが完了するのを待ってください。

対応モデルは PLaMo 3 Translate 0.8B（英語→日本語）です。この系列以外の GGUF は対象外となります。「ライセンス・利用条件」からモデルの利用条件をご確認ください。

選択したモデルは現在の閲覧セッションで使用します。次回起動時には、同梱されている固定名の GGUF が自動的に読み込まれます。

文書データの扱い

  • 翻訳はコンピューター内で処理します。外部の翻訳サービスへの原文送信は対象外です。
  • 入力PDFとGGUFは読み取り専用で開きます。入力ファイルの変更、削除、コピーは対象外です。
  • 状態とキャッシュはメモリ内で管理します。原文、訳文、読書位置、モデルの選択、設定、診断情報はアプリ終了時に破棄されます。
  • ファイル出力は非対応です。作業ファイル、一時ファイル、状態DB、設定、履歴、ログ、lockの自動作成、訳文やセッションの保存・書き出しは対象外です。

「この起動中に開いたPDF」の一覧は終了時に破棄されます。文章や診断情報をコピーすると、その内容がOSのクリップボードに渡されます。

0.1.1以前を使ったことがある方へ

0.1.1以前のバージョンでは、永続保存と書き出しの機能が備わっていました。現在のバージョンでも、旧版で作成された保存データはそのまま保持され、管理は利用者が行います。保存場所については、セッションデータの仕様をご覧ください。

困ったときは

同梱モデルを選ぶ画面が開く

ZIPファイルをフォルダー単位で解凍し、アプリ本体と plamo-3-translate-0.8b-Q4_K_M.gguf を同じ階層に置いてください。Macをご利用の場合は、.app の外側に GGUF を配置します。さらに、「モデル設定」から手動で GGUF を選択することもできます。

訳文の表示を確認する

画面下部でモデルの読み込み状況を確認し、「翻訳」→「現在ページを自動翻訳」を有効にしてください。画像で構成された PDF は文字抽出や翻訳の対象外です。非常に複雑なページでは自動文字抽出が停止することがありますが、PDF の閲覧は引き続き行えます。

モデルの読込みや翻訳が失敗する

「モデル設定」に表示されるエラーメッセージを確認し、該当する PLaMo 3 Translate 0.8B GGUF を選択してください。ページが長いと、モデルの入力・出力容量や利用可能メモリの上限に達することがあります。画面の状態を確認し、メモリが不足している場合は、他のアプリを終了して確保してください。

パスワードの入力やページの読込みエラーに対処する

パスワードが設定された PDF を開くと入力画面が表示されますので、そこでパスワードを入力してください。ページが破損して読込みエラーが起きたときは、別のページへ移動することで閲覧できる場合があります。

再起動すると読書位置や設定が戻る

アプリは終了時に、メモリ内に保持している訳文・読書位置・設定・履歴をすべて破棄します。再起動したら、PDF を再度開いて閲覧してください。

問題を報告したい

「ヘルプ」→「診断情報をコピー…」を選択すると、診断情報を確認でき、コピーも可能です。公開する内容を確認したら、GitHub Issuesに OS、アプリのバージョン、問題が起きた操作、画面に表示された状態を記入してください。公開の可否を確認する前に PDF を添付することは禁止されています。
