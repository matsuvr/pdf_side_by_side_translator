01 / GET STARTED

はじめに

Offline PDF Translatorは、PDFの原文を左、日本語訳を右に並べて読むためのデスクトップアプリです。同梱のPLaMo 3 Translate 0.8Bが、PDFから抽出した英語の原文を日本語に翻訳します。

このページはアプリの操作マニュアルです。

翻訳はダウンロードしたアプリで行います。本文は閲覧・選択・コピー用で、文書の編集や保存・書き出しには対応していません。

1. ZIPをダウンロードして展開する

最新のリリースページの「Assets」で、OSに合うアプリ用ZIPを選び、フォルダーごと展開します。「Source code」はアプリ用ZIPではありません。

2. アプリとモデルを同じフォルダーに置く

ZIPには翻訳モデルとライセンス文書が入っています。モデルをアプリから離さず、展開したフォルダーのまま使ってください。

展開したフォルダー/
├─ offline-pdf-translator.exe（Windows）
│  または Offline PDF Translator.app（Mac）
├─ plamo-3-translate-0.8b-Q4_K_M.gguf
├─ PLaMo-Community-ja.txt
├─ LICENSE
├─ THIRD_PARTY_NOTICES.txt
└─ README.md

MacではGGUFを.appの外側の同じ階層に置きます。.appの中へ入れる必要はありません。

3. アプリを起動してPDFを開く

アプリは同じフォルダーのGGUFを自動で読み込みます。「PDFを開く」ボタン、または「ファイル」→「PDFを開く…」からPDFを選んでください。現在のページの翻訳が自動で始まります。

初回起動時にモデルの利用条件が表示されたら、内容を確認してください。同梱GGUFが見つからない場合はファイル選択画面が開きます。キャンセルしてもPDFは閲覧でき、後から「モデル設定」でモデルを選べます。

Macで初めて起動するとき

起動がブロックされた場合は、「システム設定」→「プライバシーとセキュリティ」→「アプリケーションの実行許可」で、Offline PDF Translatorの「このまま開く」を選んで実行を許可してください。

現在のWindows配布実行ファイルは未署名です。ダウンロード元が、このプロジェクトのGitHub Releasesであることを確認してください。

02 / READING

PDFを読む

原文と訳文を見比べる

左側にPDF、右側に現在のページの日本語訳を表示します。中央の境界をドラッグすると、左右の幅を調整できます。「表示」→「左右を均等にする」で同じ幅に戻せます。

ページを移動する

原文の左右の矢印で前後のページへ移動します。原文枠のページ番号に読みたい番号を入力してEnterを押すと、そのページに移動します。Ctrl / ⌘ + G でもページ番号欄へ移動できます。

PDFの倍率・向きを変える

原文枠上部の倍率欄で「幅に合わせる」「ページ全体」や倍率を選びます。倍率を入力してEnterを押すこともできます。「表示」メニューでは「左回転」「右回転」も選べます。

訳文の文字サイズを変える

「表示」→「訳文の文字サイズ…」からポイント数を指定します。PDFの倍率とは別に調整できます。

処理の状態を確認する

PDF読込み中と翻訳中には、点が循環する動作表示が出ます。画面下部のステータスバーには、モデルの読込み状態や、コンピューター全体のCPU使用率の概算などが表示されます。翻訳にかかる時間は、ページの長さとコンピューターの性能によって変わります。

03 / FIND & COPY

検索・選択・コピー

PDF内を検索する

  1. 「選択・コピー」→「PDF内を検索…」、または Ctrl / ⌘ + F で検索欄を開きます。
  2. 検索語を入力します。「前の結果」「次の結果」で移動できます。
  3. 必要に応じて「英字の大文字・小文字を区別」を選びます。「閉じる」または Esc で検索欄を閉じます。

検索対象はPDFから抽出できる原文です。画像だけのページや、文字情報が多く検索を省略したページでは、結果を見つけられないことがあります。

必要な文章をコピーする

原文または訳文の文章を選び、Ctrl / ⌘ + C を押します。「選択・コピー」→「ページの原文をコピー」で、現在のページから抽出した原文をまとめてコピーできます。

本文は読み取り専用です。入力、貼り付け、切り取り、削除、Undoによって文書を変更することはできません。検索語、ページ番号、倍率、モデルの場所は入力できます。

04 / TRANSLATION

翻訳の設定

現在のページを自動で翻訳する

「翻訳」→「現在ページを自動翻訳」は、起動時に有効です。ページを開く・移動することで、そのページの原文を翻訳します。自動翻訳を止めたいときは、この項目のチェックを外します。

日本語の文体を選ぶ

「翻訳」メニューから「標準文体」または「やさしい文体」を選びます。「やさしい文体」は、やさしい日本語での翻訳をモデルに指定します。

訳文は原文と照らし合わせてお読みください。

モデルによる翻訳には、誤訳や情報の抜けが生じることがあります。画像内の文字を認識するOCR機能はありません。PDFから文字を抽出できない場合も、PDF自体は閲覧できます。

05 / MODEL

モデル設定

通常はZIPに入っている plamo-3-translate-0.8b-Q4_K_M.gguf をそのまま使えます。モデルを手動で選ぶときは、次の手順で設定します。

  1. 「モデル設定」→「モデルを選択…」を開きます。Ctrl / ⌘ + , でも開けます。
  2. 「ファイルを選択…」で対応するGGUFを選びます。
  3. 「OK」を押して読込みを待ちます。

対応モデルはPLaMo 3 Translate 0.8B（英語→日本語）です。任意のGGUFに対応しているわけではありません。「ライセンス・利用条件」でモデルの利用条件を確認できます。

モデルの選択は、この起動中だけ有効です。次回起動時は、同梱の固定名のGGUFを読み込みます。

07 / YOUR DOCUMENTS

文書データの扱い

  • 翻訳はコンピューター内で処理します。PDFの原文を外部の翻訳サービスへ送信しません。
  • 入力PDF・GGUFは読み取り専用で開きます。アプリから入力ファイルの変更・削除・コピーは行いません。
  • 状態とキャッシュはメモリ内に置きます。原文、訳文、読書位置、モデルの選択、設定、診断情報は終了時に破棄します。
  • ファイル出力は行いません。作業ファイル、一時ファイル、状態DB、設定、履歴、ログ、lockを自動作成しません。訳文やセッションの保存・書き出し機能もありません。

「この起動中に開いたPDF」の一覧も、次回の起動には引き継ぎません。選択した文章や診断情報をコピーすると、内容はOSのクリップボードへ渡されます。

0.1.1以前を使ったことがある方へ

以前の版には永続保存・書き出し機能がありました。現行版は旧版の保存データを自動で削除しません。旧版データは利用者が管理します。保存先はセッションデータの仕様をご確認ください。

08 / TROUBLESHOOTING

困ったときは

「同梱GGUFが見つかりません」と表示される

ZIPをフォルダーごと展開し、アプリと plamo-3-translate-0.8b-Q4_K_M.gguf が同じ階層にあるか確認してください。Macでは.appの外側に置きます。「モデル設定」でGGUFを手動選択することもできます。

PDFは見えるのに、訳文が表示されない

モデルの読込みが終わっているか、画面下部の状態を確認してください。「翻訳」→「現在ページを自動翻訳」が有効かも確認します。画像だけのPDFは文字を抽出できないため翻訳できません。非常に複雑なページでは自動文字抽出を止めますが、PDFは引き続き閲覧できます。

モデルを読み込めない・翻訳が途中で止まる

「モデル設定」に表示されるエラーを確認し、対応するPLaMo 3 Translate 0.8B GGUFを選んでください。長いページでは、モデルの入力・出力容量や利用できるメモリの制限に達する場合があります。表示された状態を確認し、必要に応じて他のアプリを終了してメモリを確保してください。

パスワードを求められる・一部のページを読めない

パスワード付きPDFは、表示された画面にパスワードを入力します。ページが壊れている場合は、別のページへ移動して閲覧できることがあります。

再起動すると読書位置や設定が戻る

仕様どおりの動作です。終了時に訳文、読書位置、設定、履歴を破棄するため、次回はPDFを開き直してください。

問題を報告したい

「ヘルプ」→「診断情報をコピー…」で診断情報を確認・コピーできます。内容に公開したくない情報が含まれていないか確認してから、GitHub Issuesへ、OS、アプリの版、発生した操作、表示された状態をお知らせください。公開してよい文書か確認せずにPDFを添付しないでください。
